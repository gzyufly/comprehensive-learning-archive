## 2. 三条使用规则

1. **母版不动，先复制后填写。** 工具箱和 `assets\` 里的文件都是空白母版；用时先复制到对应年级的项目文件夹，再在副本上填写。切勿直接改母版（否则下一届无模板可用）。
2. **格式与软件对应。** `.docx` / `.xlsx` 用 Word 或 WPS；`.xmind` 必须用 XMind 打开；`.xls` 是旧版 Excel 格式（能开，但建议另存为 `.xlsx` 再分发）。
3. **成品按五阶段归档。** 填完的表不是随手放，而是落到第 3 节对位表指定的位置——这决定明年还能不能被检索到。

## 4. 四条工作主线（角色 × 时序）

### 4.1 组长线（年级组长，开学初主导）

大概念与目标表述（1—1）→ 课程设计和实施结构图（1—2）→ 主题实施进度表（1—3）→ 收齐各项目负责人填的对齐表做组长汇总（1—4）→ 收齐各项目统筹表做组长汇总（1—5）→ 汇总结题材料。

### 4.2 项目负责人线（每个子课题/项目一位老师）

从组长处领到本项目目标 → 填对齐表（2—1）→ 填项目设计&任务分解统筹表（2—2）→ 做三角模型要素清单（2—3）→ 按进度表推进 → 结题后写复盘反思表。

### 4.3 进度线（统筹）

年度整体进度表（`综合性学习课程整体进度表`）定全年节点 → 各项目拆分出单项目进度表（`项目课程实施进度表`）→ 归档到"3、各项目实施进度表"。

### 4.4 复盘线（结题后）

按《1、综合性学习复盘》做项目复盘 → 提炼课程基因并编码（`2、课程基因标准化编码卡片`）→ 汇总（`3、基因卡汇总表`）→ 沉淀入库（`4、课程基因库（归档版）`）。

## 5. 各工具说明（字段级填写要点）

> 填写要点均译自母版原文自带的说明与示例；"常见错误"来自归档成品比对与培训讲义。

### 5.1 综合性学习课程设计工具 / 一、主题课程设计（组长）

#### 1—1、主题课程大概念及目标表述.docx

- **结构**：两张表。
  - 表一「主题大概念的分析维度与内涵」：分析维度（知识结构 / 认知方式 / 文化价值）× 核心追问 × 内涵说明 × 简要示例（母版以"桥"主题作示例）。
  - 表二「大概念及课程总目标」：大概念三行（主题知识结构 / 主题认知方式 / 主题文化价值）+ 课程目标四行（认知目标 / 文化价值观目标 / 核心素养目标 / 融合目标）。
- **填写要点**：
  - 大概念要三行合填：知识结构（什么类别、有哪些相关知识）+ 认知方式（从哪些角度、什么途径和方法去认知）+ 文化价值（当下和未来问题能形成的思想价值观、能培养哪些核心素养）。
  - 目标四维各有侧重：认知目标看知识结构与认知方式（结构角度、过去/现实/未来、地域影响等）；文化价值观目标看时代热点的文化价值观、家国情怀和国际视野的意义；核心素养目标对应创造性问题解决、批判性思维、信息素养、学会学习、社会情商、沟通与协作、公民意识和社会责任、文化认同与理解等；融合目标写多元看世界、多主体协作、多角度观察现象、多样化解决问题。
- **常见错误**：目标写成活动描述而非可测量表述；大概念过大（如"了解中国文化"）；三个分析维度只填其一。

#### 1—2、综合性学习课程设计和实施结构图.xmind

- **结构**（现行母版，约 145 个主题）：中心"课程主题"下 12 大分支——
  - **课程目标**：认知目标 / 文化价值观目标 / 核心素养目标 / 多元融合目标
  - **开题**：目的和意义 / 形式 / 内容 / 分工
  - **项目**：类型（学科参与[背景知识类 / 学科工具类 / 学科项目学习]、实践活动类[参观 / 访谈调查 / 实践体验]、综合项目类[STEAM / 跨学科整合项目学习]）+ 设计依据（主题大概念 / 课程目标 / 文化和社会背景 / 学生需求和兴趣 / 资源和条件 / 实际情况调整）
  - **结题**：目的和意义 / 形式 / 成果 / 分工
  - **评价**：课程实施（目标达成度 / 突破及不足）、师生参与（过程性评价 / 结果性评价）、复盘（过程性元认知——持续改进 / 终结性元认知——建构经验）
  - **工具设计**：概念工具（理论、愿景、模型：课程转化、大概念；拓展性学习、三角模型、循环圈）、符号工具（方案、流程、图表：课程设计结构图 / 研学单 / 目标对齐表 / 复盘反思表）、物理性工具（材料性工具）
  - **进度安排**：设计进度 / 实施进度
  - **制定规则**：教师协作评价 / 学生学习评价 / 家长参与协作
  - **组织分工**：师生家长共同体的建立 / 人员分工与任务分配
  - **选题**：选题背景（主题领域及文化价值和意义：家国情怀 / 国际视野 / 现实问题 / 未来价值 → 提炼主题大概念；符合学生实际和需求；有可供利用的资源；既有课题）、选题方式（师生家长问卷调查 / 教师头脑风暴 / 既有主题的延续迭代 / 学校命题 / 社区调研）、共商确定
  - **主题大概念**：要素（知识结构 / 思维方式 / 文化价值观）、作用（聚焦、发散）
  - **主题大概念指导**：三级目标对齐 / 项目匹配 / 纵向一致连贯 / 横向整合系统
- **填写要点**：先定主题与大概念，再展开项目类型与设计依据；把本校常用表（对齐表、复盘反思表等）挂到"符号工具"分支下，让结构图同时是一张"工具地图"。
- **常见错误**：图建成任务清单而非结构图；未随年度迭代更新（应使用最新母版）。

#### 1—3、主题课程实施进度表.xlsx

- **结构**：Sheet1「（主题名称）实施计划进度表」。列：项目（名称）| 分解任务 | 责任人 | 参与人 | 第一周 | 第二周 | 第三周 | …；行：开题 → 项目一~项目五 → …… → 综合实践 → 结题 → 复盘。
- **填写要点**（母版备注）：①该进度表是在项目统整后的基础上，在时间轴上的展开；目的是确保整体及各项目进度及相互协调；②"分解任务"可简要填写。
- **常见错误**：只写到月不到周；未留复盘时间。

#### 1—4、主题课程目标与项目课程目标对齐表（组长汇总）.docx

- **结构**：矩阵表——行 = 目标项目名（主题课程 + 项目一~四……），列 = 认知目标 | 文化价值目标 | 核心素养目标 | 多元融合目标。
- **填写要点**（母版说明）：①收集和汇总各具体项目负责人填写的目标对齐表到一张整表中；②组长带领组员纵向对比，如果项目目标出现多次重叠，可与具体项目负责人协商，适当调整项目目标及项目内容，以保证项目的统整性。
- **常见错误**：汇总时未标注支撑关系；项目目标与主题目标不对齐。

#### 1—5、项目设计统筹表（组长汇总）.docx

- **结构**：表头填年级、主题；7 列——项目名称（是什么）| 项目目标（什么目标）| 项目任务（做什么）| 预期产品/结果（做成什么）| 达成目标的表现（对相应目标进行分解，并列出证明此目标达成的具体行为）| 学习活动（学生怎么做/教师给与什么指导）| 实施时间（第？周—第？周）；行：开题 → 项目一~四 → …… → 综合实践 → 结题 → 复盘；表尾有「跨项目（项目之间）协调说明」。
- **填写要点**（母版说明）：①组长收集汇总各具体项目统筹到一张整表上；②按四步检查协调：（1）横向看，每个项目的设计，确保内在一致、有效——表现性任务（UBD）；（2）纵向看，项目要按照时间或逻辑顺序排列（并列、先后），不要出现相互包含项目；（3）属于一个大项目的，要合并成一个大项目，大项目也依照此表统整小项目；（4）整体看各项目的内容，是否存在重复性内容、活动，存在就整合。
- **常见错误**：漏登跨学科/综合实践项目；项目互相包含未合并；"达成目标的表现"空挂（没有可观测行为）。

### 5.2 综合性学习课程设计工具 / 二、项目课程设计（每个项目负责人）

#### 2—1.主题课程目标与项目课程目标对齐表.docx

- **结构**：与 1—4 同构（四维目标 × 主题课程/各项目）。
- **填写要点**（母版说明）：①"主题课程"目标指"课程总目标"；"项目课程"目标是具体项目的目标，与主题课程目标相对应，从而保证课程目标的一致性；②具体"项目课程"目标所对应横向的四维目标，有几个填几个，没有的维度则不用填；③如果项目目标出现多次重叠，可适当调整项目目标及项目内容，以保证项目的统整性（组长收集汇总各项目目标后检查，并与具体项目负责人协商调整）。
- **常见错误**：目标与主题目标无对应关系；四个维度硬凑全填。

#### 2—2、项目设计&任务分解 统筹表.docx

- **结构**：两张表。
  - 表一「项目设计统筹表（概括填写）」：项目名称与类型（跨学科项目、学科项目、综合实践、Steam、子课题）| 项目目标 | 项目任务 | 预期产品/结果 | 达成目标的表现 | 学习活动 | 完成时间（第？—第？周）。
  - 表二「项目任务统筹表（具体填写）」：任务名称 | 目标和作用 | 任务内容（做什么）| 预期产品/结果 | 达成目标的表现 | 学习活动 | 实施时间；行 = 任务一 / 任务二 / 任务三。
- **填写要点**：先概括后具体；每个任务都必须写"目标和作用"，避免为活动而活动；任务要有明确产出物。
- **常见错误**：任务粒度过粗（一个任务跨数周）；无明确产出物；两表内容脱节。

#### 2—3、项目三角模型（要素清单）.docx

- **结构**：教师版 + 学生版两份同构表；列 = 要素 | 要素解读 | 项目运用；7 要素 = 主体 / 客体 / 结果 / 工具 / 共同体 / 规则 / 分工。
- **填写要点**：
  - 教师版：主体 = 教师（主要负责人、协助人）；客体 = 设计和实施项目，达成课程目标；结果 = 形成新认知、新工具、新模式（可在活动结束后反思再填写，或先进行预设）；工具 = 组织方案 + 三类工具（概念工具：理论、愿景、模型；符号工具：方案、流程、图表；物理工具：材料性、技术性）；共同体 = 学科教师、家长、班主任、不同组学生；规则 = 活动及共同体成员之间的规范、约定和标准（定期沟通、协调、通告、与家长互动）；分工 = 共同体内的角色分工、任务分配。
  - 学生版：主体 = 学生；客体 = 活动及产品；结果 = 课程目标（对应项目统筹表里的"项目目标"）；工具 = 学习方案、支持性工具（三类工具）；共同体 = 教师、家长、不同组学生（教师：指导；家长：辅助；学生：分工、互助）；规则 = 活动及同学间的规范、约定和标准；分工 = 教师、家长、同学组内的角色分工、任务分配。
