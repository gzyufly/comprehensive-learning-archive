## 2. 三条使用规则

1. **母版不动，先复制后填写。** 工具箱里的文件是空白母版；用时先复制到对应年级的项目文件夹，再在副本上填写。切勿直接改母版（否则下一届无模板可用）。
2. **格式与软件对应。** `.docx` / `.xlsx` 用 Word 或 WPS；`.xmind` 必须用 XMind 打开；`.xls` 是旧版 Excel 格式（能开，但建议另存为 `.xlsx` 再分发）。
3. **成品按五阶段归档。** 填完的表不是随手放，而是落到第 3 节对位表指定的位置——这决定明年还能不能被检索到。

## 4. 四条工作主线（角色 × 时序）

### 4.1 组长线（年级组长，开学初主导）

大概念与目标表述（1—1）→ 课程设计和实施结构图（1—2）→ 主题实施进度表（1—3）→ 收齐各项目负责人填的对齐表做组长汇总（1—4）→ 收齐各项目统筹表做组长汇总（1—5）→ 汇总结题材料。

### 4.2 项目负责人线（每个子课题/项目一位老师）

从组长处领到本项目目标 → 填对齐表（2—1）→ 填项目设计&任务分解统筹表（2—2）→ 做三角模型要素清单（2—3）→ 按进度表推进 → 结题后写复盘反思表。

### 4.3 进度线（统筹）

年度整体进度表（`综合性学习课程整体进度表`）定全年节点 → 各项目拆分出单项目进度表（`项目课程实施进度表`）→ 归档到"3、各项目实施进度表"。

### 4.4 复盘线（结题后）

按《1、综合性学习复盘》做项目复盘 → 提炼课程基因并编码（`2、课程基因标准化编码卡片`）→ 汇总（`3、基因卡汇总表`）→ 沉淀入库（`4、课程基因库（归档版）`）。

## 6. 术语表

| 术语 | 含义 |
|---|---|
| 大概念 | 主题背后可迁移的核心理解，是目标表述的锚点 |
| 目标对齐 | 项目目标与主题目标的支撑关系校验，组长汇总把关 |
| 任务分解 | 把项目拆为有负责人、时序、产出的可执行任务 |
| 三角模型 | 项目核心要素的结构化梳理方式（配套设计表与 pptx 两种呈现） |
| 统筹表 | 汇总型表格：组长看全局、负责人看单项目 |
| 课程基因 | 结题后提炼出的可复用课程要素，编码入库供下届取用 |
| 一致性 / 连贯性 / 统整性 | 项目课程设计的三个评判原则（见培训讲义） |

## 7. 使用约束与坑点

- **二进制不可读**：`.doc`/`.docx`/`.xls`/`.xlsx`/`.db` 不能用 Read 工具直接读，需 Word/WPS/Excel 打开；`.xmind` 需 XMind。
- **`~$` 开头是 Office 临时锁文件**（如 `~$3、主题课程实施进度表.xlsx`），说明该文件正被 Office/WPS 打开，一律忽略、切勿复制或打包。
- **母版与成品的关系**：母版在工具箱/技能 assets 内，成品在项目文件夹；填写前必须先复制。
- **早期学年命名不同**：检索历史项目时按语义路径找，不要硬编码文件夹名。
- **结构图版本**：以 `综合性学习课程设计工具\一、主题课程设计（组长）\1—2、…结构图.xmind` 为现行母版，`2024-8` 与 `2023-2-17` 版仅作演进参考。
- **基因库的传播范围**：课程基因库属学校课程核心成果，随技能分发前需确认其中不含内部评审信息。
