# 综合性学习资料库结构手册（通用版）

> 本手册描述"综合性学习 / 综合实践"项目资料库的**通用组织方式**，供索引脚本与日常的"按年级组查询/调整"任务参考。与 `scripts/index_projects.py` 保持一致。
> 不同学校的文件夹命名各不相同，**核心是"按年级关键词识别 + 五阶段框架"**，具体命名请用 `config.json` 适配。

## 1. 顶层结构（典型）

归档根目录下通常包含三类内容：

1. **学年/学期文件夹**（项目主体，每年一组）：命名多形如 `2024—2025第二学期`、`2024—2025学年`、`2025级` 等。索引脚本通过 `year_keywords`（默认含"学年/学期/续期"）与 `YYYY—YYYY` 前缀识别。
2. **公共/跨年级资料目录**（不属于任何年级组，查询年级项目时排除）：如 `优秀项目申报材料`、`学科教学`、`主题推荐资料` 等。各校名称不同，脚本会自动跳过"嵌套的学年文件夹"和无法识别年级的目录。
3. **根目录文件/快捷方式**：历年主题总表（多为二进制 `.doc`/`.docx`，需用 Word/WPS 打开，不可用 Read 直接读取/改写）、服务器快捷方式、同步缓存等，查询时忽略。

## 2. 年级项目文件夹命名（关键：不统一）

每个学年文件夹内，各年级组一个项目文件夹。命名**无统一模板**，但都包含年级关键词。识别年级必须靠"年级关键词正则"，不能靠主题或前缀。

**默认年级识别（可在 config.json 的 `grades` 中覆盖）：**

```
九年级 八年级 七年级 六年级 五年级 四年级 三年级 二年级 一年级
```

脚本识别年级的规则（避免误判）：
- **优先匹配完整年级名**：如 `八年级` / `高一` / `小班`。
- **其次匹配数字简写**：中文/阿拉伯数字 + 可选 `[上下]` + 可选"年级"，如 `八下` / `三` / `3年级`。
- **仅当以上都不匹配时才认为该文件夹不是年级项目**。因此"一花一世界""千年羊城"里的"一"不会误判成一年级。

> 若贵校是高中（高一/高二/高三）、幼儿园（小班/中班/大班）或其他分段，请在 `config.json` 的 `grades` 中改写为贵校实际年级列表即可，简写（八下/三上 这类）会被自动支持。

**主题抽取规则**：脚本自动剔除年级关键词及常见修饰词（引号、括号、破折号、"综合性学习/资料集/课程"等后缀），得到"主题"字段。例如 `“AI未来”——八年级综合性学习` → 主题 `AI未来`，年级 `八年级`。

## 3. 年级项目内部五阶段框架（默认模板）

绝大多数学校的项目内部都遵循一套**较稳定的五阶段框架**（字段名可能略有差异，但阶段顺序一致）。这也是 `--scaffold` 默认生成的骨架：

```
X年级综合性学习/
├─ 一、课程设计
│   ├─ 1、主题课程设计
│   └─ 2、项目课程设计与实施设计
├─ 二、开题资料
├─ 三、项目实施
│   ├─ 1、子课题项目资料（每个子课题：教学资料/学习成果）
│   └─ 2、综合实践资料
├─ 四、结题资料
│   ├─ 1、结题方案
│   ├─ 2、结题素材（视频/展板/结题ppt/照片）
│   ├─ 3、复盘反思表
│   └─ 4、结题新闻稿
└─ 五、教师总结性材料
```

> 贵校若使用不同的阶段划分，请在 `config.json` 的 `stages` 中自定义（见 README 与 config.example.json）。

**子课题**：每个年级项目下通常有 3–5 个子课题，子课题文件夹一般含 `教学资料/` 与 `学习成果/` 两大部分。

## 4. 常见目标文件检索关键词

| 目标 | 推荐 Glob/Grep 模式 |
|------|---------------------|
| 开题方案 | `*开题方案*` / `*-开题*.pdf` |
| 开题导学案/主持稿 | `*开题导学案*` / `*主持稿*` |
| 结题新闻稿 | `*结题新闻稿*` / `*圆满收官*` |
| 复盘/反思表 | `*复盘*` / `*反思*` |
| 三角模型 | `*三角模型*` / `*三角模型设计表*` |
| 展板 | `*展板*` |
| 对齐表/统筹表 | `*对齐表*` / `*统筹表*` |
| 实施进度表/计划 | `*进度表*` / `*实施计划*` |
| 视频素材 | `*.mp4` / `*.mkv` |
| 照片 | `*.jpg` / `*.JPG` / `*.jpeg` / `*.png` |

## 5. 操作约束

- **路径含中文、全角引号 `“”`、破折号 `——`、顿号 `、`**：所有 shell/Python 调用用双引号包裹完整路径。
- **照片文件名常无意义**：多为相机原始名（如 `1D1A9862.JPG`、`DSC08326.JPG`），仅靠文件名无法判断内容，必要时抽样打开或向用户确认。
- **历史嵌套**：个别年份文件夹内可能含有更早的"学年"子文件夹（迁移残留），索引脚本默认只取"直接属于学年文件夹的年级项目"，遇到可疑嵌套向用户确认。
- **二进制总表**：历年主题总表（`.doc`/`.docx`）改动须用 Word/WPS，不可用 Read 直接读/写。
- **只读先查、写入后核对**：任何新增/移动/重命名，先 `--tree` 定位目标，再操作，最后列目录核对。
