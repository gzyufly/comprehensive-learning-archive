# 提示词速查卡（按角色）

在 WorkBuddy 对话里**直接复制下面的话**，把【】里的内容换成本校实际信息即可。无需记命令，说人话就能触发本技能。

> 提问带的信息越准，回答越准：**年级 + 学年 + 阶段/文件名**三要素尽量说全，例如"八年级 2024—2025第二学期 四、结题资料 里的复盘反思表"。

## 一、年级组长（主题课程设计 + 全年统筹）

| 想做什么 | 直接这样说 |
|---|---|
| 不知道从哪下手 | "【三年级】主题课程怎么设计？第一步填什么表" |
| 写大概念与目标 | "主题课程大概念怎么写？目标表述要注意什么" |

| 统筹全年设计 | "项目设计统筹表（组长汇总）每一栏填什么" |

技能行为：按"组长线"给出工具顺序（大概念与目标 → 结构图 → 主题进度 → 对齐汇总 → 统筹汇总），并指出每张表的关键栏目、填写说明与归档落点。

## 六、提问技巧（四句话让回答更准）

1. **带上年级和学年**：说"八年级 2024—2025第二学期"，比"上学期"准确。
2. **带上阶段或文件名**：说"四、结题资料 里的复盘反思表"，比"结题那个表"好找。
3. **说清自己的角色**：问"我是项目负责人，任务分解统筹表怎么填"，技能会直接给对应版本的要点，不会拿组长版混淆你。
4. **模板类问题加"空白"二字**："空白的三角模型要素清单"会拿到未填写的母版；不加则可能给到往年成品范例。
5. **按主题找历届项目时用短关键词**：搜"小豆"比搜"小豆子大世界"命中率高；大小写不敏感（说"ai"也能匹配"AI未来"）。
